# 内容生产流程

> 论文阅读器的深度内容（摘要、创新点、方法、结论、思维导图）如何产出。

## 1. 总体策略：LLM 生成 + 人工审核入库

纯人工录入 95 篇经典论文加每周新增，工作量不可持续；运行时实时调 LLM 则结果不稳定、有延迟、需暴露密钥。因此采用**离线生成、人工审核、版本化入库**：

```
元数据 + 可获取的文本素材
        │
        ▼
  generate-reading.ts（调 LLM）
        │
        ▼
  content/draft/<id>.json    status: "draft"
        │
        ▼
     人工审核 ──不通过──▶ 打回重生成或人工改写
        │
       通过
        ▼
  content/reviewed/<id>.json  status: "reviewed" + reviewedAt
        │
        ▼
      构建期并入页面（线上可见）
```

**只有 `status: reviewed` 的内容才会出现在生产站点上。**

## 2. 草稿生成

### 输入

| 字段 | 来源 | 必需 |
|---|---|---|
| 标题（中/英） | 数据源 | 是 |
| 摘要原文 | 数据源 / arXiv | 是 |
| 作者、年份、venue | 数据源 | 否 |
| 正文 | PDF 解析（如可得） | 否，有则质量显著提升 |

### 输出

严格符合 `ReadingContent` schema（见 PRD 3.2）。生成时使用的提示词模板放 `scripts/prompts/reading.ts`，随代码版本化。

### 硬性生成规则

1. `abstract` 中文，≤200 字。
2. `keyPoints` 3—5 条，每条一句话，不写空话（禁止「具有重要意义」「为后续研究奠定基础」这类无信息量的表述）。
3. `method.design` 2—5 条，必须是具体设计（如「用组内相对得分替代价值网络」），不是抽象描述。
4. `conclusion.findings` 与 `conclusion.impact` 分开写：前者是论文自己得出的结论，后者是对领域的影响。
5. `mindmap` 至少 3 层，叶子节点总数 8—20 个；每个节点 `label` 不超过 12 字，`note` 不超过 60 字。
6. 生成结果一律标记 `status: "draft"`、`generatedBy: "llm"`。

## 3. 审核清单

审核人（人或 agent）逐项确认：

- [ ] 标题与作者、年份、venue 与原文一致
- [ ] 摘要准确，未夸大或缩小原论文范围
- [ ] 创新点是本文**真正**的贡献，而非该领域的通用背景
- [ ] 方法描述中的每个具体设计都能在原文找到对应
- [ ] **所有数字、指标、百分比均已回原文核对**（这条最容易被 LLM 编造）
- [ ] 结论区分了「论文结论」与「外部影响」
- [ ] 思维导图层级合理，节点文字无截断、无重复
- [ ] 无事实性错误、无幻觉引用

**无法核实的数字一律删除，不允许保留「大概是」。**

## 4. 状态与可见性

| status | 存放位置 | 生产可见 | UI 标注 |
|---|---|---|---|
| `draft` | `content/draft/` | 否 | — |
| `reviewed` | `content/reviewed/` | 是 | 无标注，默认可信 |

若将来开放草稿预览，UI 必须显式标注「自动生成，未经审核」。

## 5. 内容分层（应对量的压力）

每周新增几十篇，全部做深度解读不现实。按优先级分层：

| 层级 | 内容 | 目标覆盖率 |
|---|---|---|
| L0 元数据 | 标题、来源、时间、摘要、链接 | 100% |
| L1 增强摘要 | 结构化摘要 + 3 条创新点 | 每周精选 + 高分条目 |
| L2 完整解读 | 含方法、结论、思维导图 | 优先级排期，经典论文库全覆盖 |

经典论文库 95 篇目标为 **L2 全覆盖**；每周档案库目标为 **L1 覆盖精选与高分条目，L2 按排期**。

## 6. 密钥与合规

- LLM API 密钥只走环境变量（如 `OPENAI_API_KEY`、`DASHSCOPE_API_KEY`），**绝不入库**，`.gitignore` 必须排除 `.env*`。
- 生成内容属于对原论文的解读，站点需声明观点归属与原文链接。
- 不得把论文全文写入仓库，只存结构化解读与元信息。
