摘要

Modal 工程团队基于自研无代理基准测试框架 Agentless Agent Bench，在 Modal Sandboxes 中实测 NVIDIA Vera CPU（Arm 架构兼容）性能。测试剥离网络依赖，采用 50 个 Terminal-Bench oracle 解法与验证器并发运行于 Docker 容器，结果显示 Vera 在高负载下沙箱吞吐量相较主流 x86 CPU 提升约两倍。

核心观点与创新点

  • 1首次公开 Vera CPU 在 serverless 沙箱场景下的实测性能数据
  • 2提出轻量级、无代理的终端行为基准测试框架 Agentless Agent Bench
  • 3验证 Vera 在高并发容器化工作负载中显著优于传统 x86 CPU
  • 4强调 Arm 架构在低延迟、高密度沙箱部署中的潜力
  • 5测试完全剥离网络调用，聚焦纯计算与容器调度性能

主要方法

要解决的问题
评估新型 Arm 架构 CPU（NVIDIA Vera）在 serverless 沙箱环境中的真实吞吐能力
整体思路
构建可控、去干扰的终端行为基准，对比多款 CPU 在 Modal Sandboxes 中的并发执行效率
关键设计
  • 设计 Agentless Agent Bench：50 个独立 Terminal-Bench oracle 解法+验证器
  • 所有任务在隔离 Docker 容器中运行，禁用网络 I/O
  • 统一 Modal runtime 环境，仅变量为底层 CPU 型号与架构
  • 以单位时间完成的 oracle 验证次数为吞吐核心指标
  • 采用多轮压力递增测试，覆盖中低至高负载区间
实验设置
Modal Sandboxes 环境；Vera CPU 与多款 x86 CPU（型号未公开）对比；Docker 容器并发规模动态适配；测试脚本开源详见原文

结论与影响

论文结论
NVIDIA Vera CPU 在 Modal Sandboxes 高负载场景下实现近两倍吞吐提升，证实其在密集型无状态计算沙箱中的架构优势。
对领域的影响
为 serverless 平台选用 Arm 架构 CPU 提供首个工程级实证，推动异构计算在 FaaS 场景落地。
局限
测试未涵盖 GPU 加速、持久存储 I/O 及长时任务调度等维度；Vera 量产状态与生态支持程度未说明
