Pretraining data filtering in open-weight biological models

摘要

面壁智能基于 PostTrainBench 对1338条完整后训练轨迹进行分析，覆盖7个基准、4种基座模型及多种工具环境。研究将Agent能力解耦为执行层与策略层，发现其在单次运行全后训练流程中极少中途切换初始策略，表明策略决策具有高度稳定性。

核心观点与创新点

  • 1首次系统量化分析大规模后训练Agent的实际策略行为
  • 2策略层决策表现出强一致性：98%+轨迹全程未切换初始训练策略
  • 3执行层错误（如工具调用失败）不触发策略重规划，仅靠容错机制修复
  • 4策略稳定性与基座模型能力正相关，但与具体基准/工具关联较弱
  • 5提出‘策略-执行’双层解耦框架，为Agent可解释性评估提供新维度

主要方法

要解决的问题
缺乏对后训练Agent真实策略动态的实证观测与归因分析
整体思路
构建轨迹级行为审计框架，对PostTrainBench中1338条端到端训练轨迹进行策略状态标注与切换检测
关键设计
  • 定义策略节点：每个轨迹起始时明确选择的训练范式（SFT/RL/DA等）
  • 设计切换判定规则：仅当主动调用策略重规划模块且输出新范式时记为切换
  • 执行层异常标记：区分工具失败、超时、结果无效等非策略类中断
  • 跨模型/基准/工具三维度统计策略稳定性分布
实验设置
7个基准、4个基座模型（Qwen、Llama、Phi、Gemma）、Claude Code / Codex CLI / OpenCode 工具环境，单H100卡10小时限制

结论与影响

论文结论
Agent在完整后训练流程中策略切换率低于2%，策略层远比执行层稳定；执行层容错能力是保障流程完成的关键
对领域的影响
挑战了‘Agent需频繁反思重规划’的常见假设，推动面向生产级AI工作流的稳健性评估范式
局限
未覆盖多卡分布式训练场景；策略稳定性在长周期（>24h）或对抗性干扰下的表现尚不明确
