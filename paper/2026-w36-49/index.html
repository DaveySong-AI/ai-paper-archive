摘要

Stanford 提出 Prefix Sliding 方法，在长推理生成过程中动态滑动保留关键前缀（指令与工具调用）及末尾数千 token，丢弃中间冗余 token，实现内存占用恒定、无需微调即可提速 3 倍，性能媲美全注意力机制，并支持超 100k token 的强化学习 rollout。

核心观点与创新点

  • 1无需训练或模型修改，即插即用适配现有大模型
  • 2通过前缀+尾部滑动窗口机制实现 O(1) 内存增长
  • 3在长推理任务中吞吐量提升约 3 倍，精度无损
  • 4显式保留指令与工具调用前缀，保障推理连贯性
  • 5首次验证其在超长 RL rollout（>100k token）中的可行性

主要方法

要解决的问题
长上下文推理中全注意力导致的内存爆炸与延迟激增
整体思路
运行时动态截断中间 token，仅维护语义关键片段
关键设计
  • 定义指令-工具前缀为不可丢弃核心
  • 设置固定大小尾部滑动窗口保留最新推理状态
  • 在生成每步后触发 token 重映射与 KV 缓存压缩
  • 采用位置偏移补偿机制维持注意力相对位置感知
实验设置
测试基于 Llama-3 和 Qwen 的长思维链与工具调用任务；序列长度覆盖 32k–128k；对比全注意力与 StreamingLLM 等基线

结论与影响

论文结论
Prefix Sliding 在零训练成本下实现恒定内存与 3 倍加速，性能与全注意力持平
对领域的影响
为 LLM 智能体、长程规划与在线 RL 推理提供实用化部署新范式
